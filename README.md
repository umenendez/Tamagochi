Descripción

Proyecto desarrollado en Java que simula una mascota virtual. El usuario debe cuidar de sus Tamagotchis, atendiendo sus necesidades para mantenerlos con vida.

Funcionalidades

Crear varios Tamagotchis con nombre e identificador único.

Consultar el estado de las mascotas.

Dar de comer.

Jugar mediante operaciones matemáticas.

Limpiar al Tamagotchi.

Controlar la suciedad con el paso del tiempo.

Morir cuando alcanza el nivel máximo de suciedad.

Matar manualmente a un Tamagotchi.
